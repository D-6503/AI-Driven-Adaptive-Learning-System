# AI-Driven Adaptive Learning and Assessment System using RAG and LLMs

## Overview
An AI-powered adaptive learning platform that automatically generates questions, evaluates answers, classifies questions using Bloom’s Taxonomy, and provides intelligent feedback using Retrieval-Augmented Generation (RAG) and Large Language Models (LLMs).

## Features
- PDF-based question generation
- Bloom’s Taxonomy classification
- AI answer evaluation
- Context-aware feedback
- Personalized learning analytics
- RAG-powered knowledge retrieval

## Technologies Used
- Python
- Flask
- LLM APIs
- RAG
- Vector Database
- Sentence Transformers
- SQLite / PostgreSQL

## Methodology
1. PDF extraction
2. Text preprocessing
3. Semantic chunking
4. Embedding generation
5. Vector database storage
6. RAG retrieval
7. LLM-based evaluation
